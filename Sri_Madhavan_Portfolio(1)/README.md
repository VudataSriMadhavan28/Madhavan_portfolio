# Sri Madhavan Vudata — Portfolio

## Run locally

1. Install Python 3.
2. Open a terminal in this folder.
3. Install Flask:

```bash
pip install flask
```

4. Start the website:

```bash
python app.py
```

5. Open the local address shown by Flask, usually:
`http://127.0.0.1:5000`

The resume is already included at `static/resume.pdf`.

## Files

- `app.py` — Flask server
- `templates/index.html` — portfolio page
- `static/style.css` — design and responsive layout
- `static/script.js` — mobile navigation
- `static/resume.pdf` — uploaded profile/resume
